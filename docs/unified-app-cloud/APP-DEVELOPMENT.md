# 欧拉应用接入与版本契约

本契约面向部署者维护的可信模块。平台不会从用户提供的 URL 下载执行代码，也不提供任意第三方代码的沙箱托管。原八个产品的仓库与部署保持独立。

## 注册一个应用

1. 在 `services/app-cloud/internal/apps/<id>` 实现 `appkit.Module`，构造函数接收 `*appkit.Runtime`。模块只能使用欧拉注入的作用域，不接收原站的人员登录凭据。
2. 在 `apps.DefaultRegistry` 注册 `appkit.Manifest` 和工厂函数。清单包含稳定 ID、名称、语义版本、API 版本、递增的 schema 版本、能力、依赖和所需部署配置。
3. 在 `platform/frontend/apps/console-base/src/cloud/apps/<id>/App.vue` 实现工作台。现有 `import.meta.glob` 会将编译时模块加入控制台，通过 `useApp()` 访问当前项目 API。
4. 如需机器接口，在平台 `access.go` 的固定路由清单明确登记支持的操作和权限，并增加越权测试。注册清单本身不授予任何机器权限。

Registry 在调用工厂、迁移或后台任务前检查清单、重复 ID、缺失依赖、循环依赖及工厂 ID，按确定的依赖顺序构建。目录 API `/api/v1/catalog` 返回当前实际加载模块的清单，启用接口从同一目录校验。依赖定义的是代码与迁移顺序；项目内应用启用及跨应用授权仍需业务逐次校验。

## 授权与数据

人员 API 使用 `/api/v1/tenants/{tenant}/projects/{project}/apps/{app}/...`。平台校验有效会话、CSRF、项目访问、归档状态和应用启用，再注入 `appkit.Scope`。每个资源查询还必须带上 `TenantID`、`ProjectID`，个人材料和申请需加 `ActorID` 检查。

`read/write/manage/secrets` 属于项目权限。`review/admin` 是单独授予且可能到期的应用权限；团队所有者不自动获得审核和运营权限。使用 `appkit.Handle` 绑定每条业务路由所需权限。公开接口要单独验证发布密钥、设备签名或一次性票据，并逐请求复核应用启用和项目归档状态。

模块表以应用 ID 为前缀。SQLite 共享单连接，事务中所有查询必须使用 `tx`；开启下一条查询前关闭 Rows。业务变更、审计和事件 outbox 应在同一事务提交。外部 SQL/S3 操作使用意图记录与幂等恢复，不把未知执行结果写成成功。

敏感字段使用 Runtime 的加密边界和明确的关联数据；不写入日志、审计摘要、目录或普通列表。新 SDK 位于 `sdk/app-cloud-python`，旧 `sdk/python` 的 CPS1 接口不属于应用云协议。

## 运行生命周期

必需方法是 `ID`、`Migrate(ctx)`、`Handler`、`PublicHandler`。可选方法由注册包装器转发：

| 方法 | 行为 |
| --- | --- |
| `DependencyStatus(ctx) map[string]string` | 只报告 `up/down/not_configured`，不返回地址、凭据或原始错误 |
| `Maintain(ctx) error` | 启动立即执行，然后每小时执行；单轮有超时，必须响应取消，失败允许下轮重试 |
| `Close() error` | 全部工作线程取消并退出后释放模块资源 |

进程先检查已记录的 schema 版本，拒绝已知的数据库降级，再执行可重复迁移。全部迁移成功后记录运行版本。新迁移必须增加清单 schema 版本并覆盖升级测试。此机制无法为任意 SQL 自动生成反向迁移；失败或不兼容发布需恢复对应版本的完整快照，再启动原镜像，步骤见 [RELEASE.md](../../deploy/app-cloud/RELEASE.md)。

## 接入验收

每个新应用至少提供真实持久化业务、跨团队/跨项目资源猜测、最低角色写入拒绝、归档/停用、秘密保护及迁移重入测试。涉及后台动作时，还需进程重启、租约过期、重试幂等和撤权后执行测试。前端应验证加载、空数据、错误、实际提交、项目切换和移动宽度，不以静态截图代替业务结果。

## 当前规模边界

应用云当前提供单实例控制面，外部数据库与对象服务由部署者配置。收费支付、多副本控制面、跨区容灾、底层数据库集群调度和不可信代码托管需要各自的独立设计与环境验收，历史 IaaS 目录不构成这些能力。

扩展前应分别确定账单与退款规则、租户限额和审计要求；验证可迁移数据库、分布式锁与会话撤销；确定副本故障与恢复目标；为任意应用定义运行隔离、网络权限、秘密和升级契约。没有这些测试，不将平台描述为可售公有云或高可用集群。
