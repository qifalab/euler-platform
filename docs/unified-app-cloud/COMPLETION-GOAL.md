## 环境验收与后续规模条件

生产 OIDC 客户端、HTTPS 域名、服务器、邮件/机器人、AI 服务和真实用户试运行需要实际部署输入。缺少这些输入时，保留待验收项和可执行验收步骤，不标记为生产完成。

上一轮建议中的收费体系、多副本/跨区高可用、底层数据库集群调度与任意第三方应用托管属于明确的条件性演进方向。本轮须评估并记录实施前提与剩余项，不能把历史 IaaS 目录算作已实现，也不能通过将 SQLite 换成 PostgreSQL 就宣称完成高可用。可收费或高可用的宣称必须另有真实端到端证据。

## 协作与集成

各模块负责人在分配目录内工作，根代理负责统一注册、页面路由、全局契约和集成。新增公开接口逐请求检查作用域、应用启用和凭据状态；审计不记录秘密。自动流程只能执行显式授权的动作，不提升人员审核/运营权限。

执行记录将在本文件追加，并在 `VALIDATION.md` 链接本次独立验收结果。
