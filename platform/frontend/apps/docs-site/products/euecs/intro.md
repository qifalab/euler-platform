# 云服务器 EUECS

辰云服务器(EUECS,Euler Elastic Compute Service)提供安全可靠、弹性可扩展的云端计算能力,是承载各类业务的基础算力。

## 产品特点

- **弹性伸缩**:支持按需扩缩容,灵活应对业务流量波动
- **高可用**:多可用区部署,故障自动迁移
- **安全隔离**:基于专有网络(VPC)的租户隔离,安全组精细化管控
- **多样规格**:通用型、计算型、内存型等多种规格,满足不同场景

## 产品组成

一台云服务器由实例、系统盘、镜像、VPC 与安全组共同构成。创建实例时需选择地域、可用区、规格与镜像,并配置网络与凭证。
