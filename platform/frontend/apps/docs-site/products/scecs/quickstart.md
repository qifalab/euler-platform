# SCECS 快速入门

本指南带您在 5 分钟内创建第一台云服务器。

## 前置条件

- 已注册辰云账号并完成实名认证
- 账户余额充足(或使用免费试用额度)

## 创建实例

1. 登录[控制台](https://console.starcloud.cn),进入「云服务器」
2. 点击「创建实例」,打开购买向导
3. **基础配置**:选择地域(如华北1)、可用区、规格(如 2c4g)、镜像(如 CentOS 7)
4. **存储与网络**:选择系统盘大小、VPC、安全组、公网带宽
5. **系统与凭证**:设置登录密码或密钥对
6. **确认下单**:确认配置与价格,选择计费方式后提交

## 连接实例

实例状态变为「运行中」后,可通过公网 IP 使用 SSH 连接:

```sh
ssh root@<公网IP>
```
